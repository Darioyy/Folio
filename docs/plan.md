# 项目实施方案

## 项目概述

**项目名称**: Web Dev & Server Deployment Practice
**项目类型**: 个人博客练手项目
**技术目标**: 掌握全栈开发、数据库操作、服务器部署

## 一、技术选型

| 技术层 | 选型 | 理由 |
|--------|------|------|
| 前端 | HTML/CSS/JS | 掌握前端基础原理，无需构建工具 |
| 后端 | Python + Flask | 轻量级框架，代码简洁，适合学习 |
| 数据库 | MySQL | 关系型数据库，生产环境标准 |

| 部署 | Linux (Ubuntu) | 主流服务器系统 |

---

## 二、数据库设计

### 表结构

1. **users** - 用户表（管理员）
2. **categories** - 分类表（文章/资源/媒体分类）
3. **posts** - 文章表（博客文章）
4. **resources** - 学习资源表（文件上传下载）
5. **media** - 媒体表（游戏截图/视频）

### 核心字段设计要点

- 所有表都有 `created_at` 时间戳
- 使用外键约束保证数据一致性
- 文件路径存储相对路径
- 状态字段使用枚举类型

---

## 三、API接口设计

### RESTful API规范

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/v1/posts | 获取文章列表 |
| GET | /api/v1/posts/:id | 获取文章详情 |
| POST | /api/v1/posts | 创建文章 |
| PUT | /api/v1/posts/:id | 更新文章 |
| DELETE | /api/v1/posts/:id | 删除文章 |

### 安全要点

- 密码必须哈希存储（SHA-256 + 盐）
- 防止SQL注入（使用参数化查询）
- 文件上传验证（类型、大小）
- XSS防护（前端转义输出）
