## 服务器部署信息

### 远程数据库配置
如需连接远程MySQL服务器，修改 `.env` 文件：

```bash
# 远程MySQL配置
MYSQL_HOST=服务器IP地址    # 例如: 123.45.67.89
MYSQL_PORT=3306
MYSQL_USER=数据库用户名
MYSQL_PASSWORD=数据库密码
MYSQL_DATABASE=数据库名
```

### 部署架构
```
远程服务器
├── Nginx (端口80/443) → 前端静态文件
│   ├── / → 前端页面
│   ├── /api/ → 代理到Flask (127.0.0.1:5000)
│   └── /uploads/ → 上传文件
├── Flask (端口5000)
│   └── API接口 (/api/v1/*)
└── MySQL (3306)
    └── ai_web_dev数据库
```

## 问题解决记录

### 问题1：数据库初始化失败
- **描述**: `ERROR 1364 (HY000): Field 'password_hash' doesn't have a default value`
- **原因**: init.sql插入用户时未提供password_hash
- **解决**: 计算密码哈希值并修改SQL语句

### 问题2：Windows终端emoji乱码
- **描述**: `UnicodeEncodeError: 'gbk' codec can't encode character`
- **原因**: Windows GBK编码不支持emoji
- **解决**: 移除emoji，使用文本标识 `[OK]` `[ERROR]`

### 问题3：缺少flask-cors模块
- **描述**: `ModuleNotFoundError: No module named 'flask_cors'`
- **解决**: 在requirements.txt添加Flask-Cors并安装

### 问题4：前端点击上传链接页面空白
- **描述**: 导航拦截了所有链接，包括页面跳转
- **解决**: 检查链接类型，只拦截锚点链接

### 问题5：上传后文件无法访问
- **描述**: 文件路径不规范，缺少静态文件服务
- **解决**: 使用绝对路径，添加 `/uploads/` 路由

### 问题6：API路由斜杠问题
- **描述**: Flask路由需要斜杠结尾
- **解决**: 统一使用带斜杠的URL

### 问题7：JavaScript中使用Python代码
- **描述**: `os is not defined`
- **解决**: 用JavaScript实现相同功能

### 问题8：前端没有登录入口
- **描述**: 用户无法进入后台
- **解决**: 添加"后台管理"导航链接

### 问题9：登录时中文乱码
- **描述**: API返回的中文显示为乱码
- **解决**: 添加 `app.config['JSON_AS_ASCII'] = False`

### 问题10：权限控制缺失
- **描述**: 普通用户可以删除他人内容
- **解决**: 实现权限验证装饰器和所有权检查

## 技术要点总结

### 权限管理
| 要点 | 说明 |
|------|------|
| 验证装饰器 | `@login_required` 保护需要登录的API |
| admin判断 | 用户名为 'admin' 即为管理员 |
| 所有权检查 | 创建者ID与当前用户ID比对 |
| 前端控制 | 根据权限显示/隐藏操作按钮 |

### 数据库交互
| 要点 | 说明 |
|------|------|
| 参数化查询 | 防止SQL注入 |
| 外键约束 | 保证数据一致性 |
| 级联删除 | 用户删除时自动删除其内容 |
| 连接重试 | `conn.ping(reconnect=True)` |

### 前后端交互
| 要点 | 说明 |
|------|------|
| Session管理 | 用于登录状态维护 |
| CORS配置 | 支持credentials跨域 |
| JSON编码 | `JSON_AS_ASCII = False` 支持中文 |
| 错误处理 | 统一的错误响应格式 |
